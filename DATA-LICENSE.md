## What the dataset does not contain

The dataset is not endorsed by Riot Games. It holds no Riot Game Information apart from the API-observed Riot IDs and API-read regions that publishers may send, which are served with their source recorded. Whether a Riot ID checked through Riot's account API counts as Game Information is to be confirmed, so those fields are kept separately and can be dropped.

Never published:

- PUUIDs, ranks, LP and match data
- live or last-played status
- raw Riot API responses
- other platform-derived data: handles, bios, counts and stream hours read from platform APIs such as Twitch or YouTube (X numeric IDs are the one exception)
- Global Contract Database rows
- Leaguepedia or Liquipedia text or lists, which are CC BY-SA and appear only as evidence URLs
